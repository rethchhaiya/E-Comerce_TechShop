# API Documentation

Base URL: `http://localhost:8080`

Authentication: none

Request/response format: `application/json`

---

## Error format

All business errors use this shape:

```json
{
  "status": 404,
  "error": "Not found",
  "message": "Category not found with id: 999"
}
```

| HTTP status | error value | Meaning |
| --- | --- | --- |
| 400 | Bad request | Invalid parent category, invalid sort field, invalid sort direction, or password longer than 72 bytes |
| 404 | Not found | Customer, category, product, address, or parent category not found |
| 409 | Duplicate | Email, slug, or product name already used |
| 409 | Conflict | Category cannot be deleted because it still has products |
| 400 | (Spring default) | Missing or invalid request fields |

## Customers

### Customer fields (used by POST and PUT)

| Field | Type | Required | Example | Notes |
| --- | --- | --- | --- | --- |
| userName | string | yes | `"Reth Chhaiya"` | Max 100 characters |
| email | string | yes | `"reth@example.com"` | Must be a valid email address |
| phone | string | yes | `"012345678"` | Max 20 characters |
| password | string | yes | `"mysecret123"` | Plain-text password. 8 characters minimum, 72 bytes maximum. The server stores a BCrypt hash |

### Customer response fields

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| id | number | `1` | Generated by the server |
| userName | string | `"Reth Chhaiya"` | |
| email | string | `"reth@example.com"` | |
| phone | string | `"012345678"` | |
| createdAt | string | `"2026-11-16T17:50:18.974963"` | ISO date-time, set by the server |

The server stores `password` as a BCrypt hash; the hash is never returned in responses.

### POST /api/customer

Create a customer. Returns `201 Created`.

```json
{
  "userName": "Reth Chhaiya",
  "email": "reth@example.com",
  "phone": "012345678",
  "password": "mysecret123"
}
```

Response:

```json
{
  "id": 1,
  "userName": "Reth Chhaiya",
  "email": "reth@example.com",
  "phone": "012345678",
  "createdAt": "2026-11-16T17:50:18.974963"
}
```

Error: `409` with message `Email already exist`.

### GET /api/customer

Returns `200 OK` with an array of customers. Empty array if none exist.

```json
[
  {
    "id": 1,
    "userName": "Reth Chhaiya",
    "email": "reth@example.com",
    "phone": "012345678",
    "createdAt": "2026-11-16T17:50:18.974963"
  }
]
```

### GET /api/customer/{id}

Returns `200 OK` with one customer.

Example: `GET /api/customer/1`

```json
{
  "id": 1,
  "userName": "Reth Chhaiya",
  "email": "reth@example.com",
  "phone": "012345678",
  "createdAt": "2026-11-16T17:50:18.974963"
}
```

Error: `404` with message `Customer not found`.

### PUT /api/customer/{id}

Update all fields of a customer. Send the same body as POST. Returns `200 OK` with the updated customer.

Example: `PUT /api/customer/1`

```json
{
  "userName": "Reth Chhaiya Jr",
  "email": "reth.jr@example.com",
  "phone": "987654321",
  "password": "newsecret123"
}
```

Response:

```json
{
  "id": 1,
  "userName": "Reth Chhaiya Jr",
  "email": "reth.jr@example.com",
  "phone": "987654321",
  "createdAt": "2026-11-16T17:50:18.974963"
}
```

Send the plain-text password again; the server stores a new BCrypt hash.

Errors: `404` with message `Customer not found`. Note: this endpoint does not check whether the new email is already used, so changing it to an existing email will fail at the database level.

### DELETE /api/customer/{id}

Returns `200 OK` with an empty body.

Example: `DELETE /api/customer/1`

Error: `404` with message `Customer not found`.

## Addresses

### Address fields (used by POST and PUT)

| Field | Type | Required | Example | Notes |
| --- | --- | --- | --- | --- |
| customerId | number | yes | `1` | ID of an existing customer |
| recipientName | string | yes | `"Reth Chhaiya"` | Max 255 characters |
| phone | string | yes | `"012345678"` | Max 20 characters |
| addressLine | string | yes | `"Street 1, Sangkat 2"` | Max 255 characters |
| city | string | yes | `"Phnom Penh"` | Max 100 characters |
| province | string | yes | `"Phnom Penh"` | Max 100 characters |
| isDefault | boolean | no | `true` | Defaults to `false` on create. On update, omit it to keep the current value. Setting it to `true` unsets the customer's previous default address |

### Address response fields

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| id | number | `1` | Generated by the server |
| customerId | number | `1` | |

| addressLine | string | `"Street 1, Sangkat 2"` | |
| city | string | `"Phnom Penh"` | |
| province | string | `"Phnom Penh"` | |
| isDefault | boolean | `true` | A customer has at most one default address |

## Categories

### Category fields (used by POST and PUT)

| Field | Type | Required | Example | Notes |
| --- | --- | --- | --- | --- |
| parentId | number or null | no | `1` | ID of the parent category. Use `null` for a top-level category |
| name | string | yes | `"T-Shirts"` | Max 255 characters |
| slug | string | yes | `"t-shirts"` | Max 255 characters, must be unique |

### Category response fields

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| id | number | `2` | Generated by the server |
| parentId | number or null | `1` | `null` for a top-level category |
| name | string | `"T-Shirts"` | |
| slug | string | `"t-shirts"` | |

### POST /api/category

Create a category. Returns `201 Created`.

Top-level category (no parent):

```json
{
  "parentId": null,
  "name": "Clothing",
  "slug": "clothing"
}
```

Child category (parent is category `1`):

```json
{
  "parentId": 1,
  "name": "T-Shirts",
  "slug": "t-shirts"
}
```

Response:

```json
{
  "id": 2,
  "parentId": 1,
  "name": "T-Shirts",
  "slug": "t-shirts"
}
```

Errors:
- `409` with message `Category slug already exists: t-shirts`
- `404` with message `Parent category not found with id: 999`
- `400` with message `A category cannot be its own parent`

### GET /api/category

Returns `200 OK` with an array of categories. Empty array if none exist.

```json
[
  {
    "id": 1,
    "parentId": null,
    "name": "Clothing",
    "slug": "clothing"
  },
  {
    "id": 2,
    "parentId": 1,
    "name": "T-Shirts",
    "slug": "t-shirts"
  }
]
```

### GET /api/category/{id}

Returns `200 OK` with one category.

Example: `GET /api/category/2`

```json
{
  "id": 2,
  "parentId": 1,
  "name": "T-Shirts",
  "slug": "t-shirts"
}
```

Error: `404` with message `Category not found with id: 999`.

### PUT /api/category/{id}

Update all fields of a category. Send the same body as POST. Returns `200 OK` with the updated category.

Example: `PUT /api/category/2`

```json
{
  "parentId": 1,
  "name": "Casual Shirts",
  "slug": "casual-shirts"
}
```

Response:

```json
{
  "id": 2,
  "parentId": 1,
  "name": "Casual Shirts",
  "slug": "casual-shirts"
}
```

Errors:
- `404` with message `Category not found with id: 999`
- `409` with message `Category slug already exists: t-shirts`
- `404` with message `Parent category not found with id: 999`
- `400` with message `A category cannot be its own parent`

Note: changing `parentId` to one of the category's own children is not checked by the API.

### DELETE /api/category/{id}

Returns `200 OK` with an empty body. Child categories are kept and their `parentId` becomes `null`.

Example: `DELETE /api/category/1`

Errors:
- `404` with message `Category not found with id: 999`
- `409` with message `Cannot delete category with id: 1 because it still has products`

## Products

### Product fields (used by POST and PUT)

| Field | Type | Required | Example | Notes |
| --- | --- | --- | --- | --- |
| categoryId | number | yes | `2` | ID of an existing category |
| name | string | yes | `"Cotton T-Shirt"` | Max 255 characters, unique inside the category |
| description | string | no | `"100% cotton, medium, blue"` | Max 2000 characters |
| isActive | boolean | no | `true` | Defaults to `true` on create. On update, omit it to keep the current value |

### Product response fields

| Field | Type | Example | Notes |
| --- | --- | --- | --- |
| id | number | `1` | Generated by the server |
| categoryId | number | `2` | |
| name | string | `"Cotton T-Shirt"` | |
| description | string or null | `"100% cotton, medium, blue"` | |
| isActive | boolean | `true` | |
| createdAt | string | `"2026-11-17T14:10:00.123456"` | ISO date-time, set by the server |

### POST /api/product

Create a product. Returns `201 Created`.

```json
{
  "categoryId": 2,
  "name": "Cotton T-Shirt",
  "description": "100% cotton, medium, blue",
  "isActive": true
}
```

Response:

```json
{
  "id": 1,
  "categoryId": 2,
  "name": "Cotton T-Shirt",
  "description": "100% cotton, medium, blue",
  "isActive": true,
  "createdAt": "2026-11-17T14:10:00.123456"
}
```

Errors:
- `404` with message `Category not found with id: 999`
- `409` with message `Product name already exists in this category: Cotton T-Shirt`

### GET /api/product

Returns `200 OK` with an array of products. Empty array if none exist. Products are newest first by default.

Query parameters:

| Parameter | Type | Default | Example | Notes |
| --- | --- | --- | --- | --- |
| sortBy | string | `createdAt` | `name` | Allowed: `id`, `name`, `createdAt`, `isActive` |
| direction | string | `desc` | `asc` | Allowed: `asc`, `desc` |
| active | boolean | not set | `true` | When set, only products with this `isActive` value are returned |

Examples:
- `GET /api/product` newest first
- `GET /api/product?sortBy=name&direction=asc` by name A-Z
- `GET /api/product?active=true&sortBy=createdAt&direction=desc` active products, newest first

```json
[
  {
    "id": 1,
    "categoryId": 2,
    "name": "Cotton T-Shirt",
    "description": "100% cotton, medium, blue",
    "isActive": true,
    "createdAt": "2026-11-17T14:10:00.123456"
  }
]
```

Errors:
- `400` with message `Invalid sort field: price. Allowed values: id, name, createdAt, isActive`
- `400` with message `Invalid sort direction: down. Allowed values: asc, desc`

### GET /api/product/{id}

Returns `200 OK` with one product.

Example: `GET /api/product/1`

```json
{
  "id": 1,
  "categoryId": 2,
  "name": "Cotton T-Shirt",
  "description": "100% cotton, medium, blue",
  "isActive": true,
  "createdAt": "2026-11-17T14:10:00.123456"
}
```

Error: `404` with message `Product not found with id: 999`.

### PUT /api/product/{id}

Update all fields of a product. Send the same body as POST. Returns `200 OK` with the updated product.

Example: `PUT /api/product/1`

```json
{
  "categoryId": 2,
  "name": "Cotton T-Shirt Slim Fit",
  "description": "100% cotton, large, black",
  "isActive": false
}
```

Response:

```json
{
  "id": 1,
  "categoryId": 2,
  "name": "Cotton T-Shirt Slim Fit",
  "description": "100% cotton, large, black",
  "isActive": false,
  "createdAt": "2026-11-17T14:10:00.123456"
}
```

Errors:
- `404` with message `Product not found with id: 999`
- `404` with message `Category not found with id: 999`
- `409` with message `Product name already exists in this category: Cotton T-Shirt Slim Fit`

Note: `createdAt` never changes. If `isActive` is omitted, the current value is kept.

### DELETE /api/product/{id}

Returns `200 OK` with an empty body.

Example: `DELETE /api/product/1`

Error: `404` with message `Product not found with id: 999`.
